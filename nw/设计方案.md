# IEEE 802.3 帧封装仿真系统架构设计文档

本项目采用 **分层解耦（Core + UI）** 架构。核心业务逻辑与算法由纯标准 C++ 实现，不依赖任何 GUI 库；表现层通过 Qt6 进行事件驱动与视图渲染。

---

### 一、工程目录结构

```text
Ethernet8023Simulator/
├── CMakeLists.txt              # 构建脚本：分立构建核心静态库、CLI 测试与 GUI 目标
└── src/
    ├── core/                   # 纯 C++ 业务内核层（无 GUI 依赖）
    │   ├── frame_types.h       # 数据契约：枚举、帧分段、单步快照与错误码
    │   ├── utils.h             # 辅助工具声明：MAC 校验、Hex/ASCII 转换、位流展开
    │   ├── utils.cpp           # 辅助工具具体实现
    │   ├── crc_engine.h        # CRC-8 计算引擎声明：多项式长除法与步进追踪
    │   ├── crc_engine.cpp      # CRC-8 计算引擎实现
    │   ├── frame_builder.h     # 封装门面声明：组装调度、Padding 补位与校验控制
    │   └── frame_builder.cpp   # 封装门面实现
    │
    ├── ui/                     # Qt6 交互与视觉表现层
    │   ├── mainwindow.h        # 主窗口控制器声明：槽函数、定时器与动画游标
    │   ├── mainwindow.cpp      # 主窗口实现：颜色分段渲染、单步控制、事件响应
    │   └── mainwindow.ui       # Qt Designer 界面布局文件
    │
    ├── main_cli.cpp            # 控制台测试入口（用于前中期算法与逻辑断言）
    └── main.cpp                # 最终 GUI 程序启动入口（初始化 QApplication 事件循环）

```

### 二、各模块文件详细职责说明

#### 1. 核心数据与契约 (`src/core/frame_types.h`)

* **定位**：纯类型定义头文件，确立各层之间的数据交互契约。
* **主要职责**：
* **错误体系**：定义 `ErrorCode` 枚举（非法 MAC、载荷超限、无效 Hex、非法多项式）及错误信息翻译函数 `error_to_string()`。
* **分段元数据**：定义 `FrameSegmentType` 枚举与 `FieldSpan` 结构体，记录前导码、MAC、长度、有效载荷、Padding 和 FCS 在全帧中的字节偏移与长度，直接服务于前端的色块联动。
* **动画快照**：定义 `CrcStepSnapshot` 结构体，记录单步长除法的位索引、当前 9 位运算窗口、是否执行 XOR、计算后余数及下一位待滑入比特。
* **帧模型**：定义 `EthernetFrame` 实体，封装各物理字段，提供 `serialize()` 导出连续字节流及 `get_checksum_payload()` 提取校验区间。
* **封装结果**：定义 `EncapsulationResult`，打包封装状态、生成的帧实体以及全量 CRC 跟踪快照列表。



#### 2. 输入清洗与基础工具 (`src/core/utils.h` / `utils.cpp`)

* **定位**：无状态的纯函数工具集。
* **主要职责**：
* **MAC 地址解析与校验**：去除分隔符（`:` 或 `-`），严格验证字符集合法性与 12 位十六进制长度，转换为固定 6 字节的 `std::array<uint8_t, 6>`。
* **Payload 编解码转换**：提供 ASCII 文本直转字节流、十六进制字符串（如 `"48 65 6C"`）转字节流，以及逆向将字节流格式化为大写 Hex 文本的方法。
* **位级别转换**：将连续的字节数组逐位展开为标准二进制位流字符串（Bit Stream），用于喂给模 2 长除法引擎。



#### 3. CRC 计算与步进追踪引擎 (`src/core/crc_engine.h` / `crc_engine.cpp`)

* **定位**：底层核心数学计算模块，专注于模 2 多项式除法及其运行时状态记录。
* **主要职责**：
* **多项式配置**：内置题目指定的 $G(X) = X^8 + X^2 + X + 1$（`100000111`，`0x107`），同时支持传入自定义多项式。
* **模 2 步进长除法**：在数据位流末尾追加 8 个 `'0'`，通过长度为 9 的滑动窗口模拟硬件移位寄存器：
* 最高位为 `'1'`：执行按位异或并打上执行标记；
* 最高位为 `'0'`：执行纯移位。


* **生成全量快照**：运算期间每推进一个比特，即实例化一个 `CrcStepSnapshot` 并存入跟踪向量，向外提供完整的历史轨迹以实现暂停、回退与单步播放。



#### 4. 帧封装调度门面 (`src/core/frame_builder.h` / `frame_builder.cpp`)

* **定位**：供上层（UI 或 CLI）调用的统一封装入口，采用门面模式（Facade）。
* **主要职责**：
* **流程控制**：依序执行“输入防御校验 $\to$ 真实长度计算 $\to$ 46 字节门限判断与 Padding 补全 $\to$ 校验序列拼接 $\to$ 驱动 CRC 引擎 $\to$ 拼接物理层前缀与 FCS”。
* **大端序控制**：确保长度字段（Length Field）和 FCS 校验和按照网络标准大端序（Big-Endian）排布。
* **产物交接**：将构建好的帧对象与跟踪快照统一打包为 `EncapsulationResult` 返回。



#### 5. 控制台验证入口 (`src/main_cli.cpp`)

* **定位**：纯 C++ 控制台程序入口。
* **主要职责**：
* 在未编写任何 GUI 代码前，通过固定用例（如短载荷、边界载荷）直接调用 `FrameBuilder`。
* 终端打印校验和、各字段 Hex Dump 及 CRC 前几步的执行快照，验证底层逻辑与算法正确性。



#### 6. Qt 交互与表现层 (`src/ui/mainwindow.h` / `mainwindow.cpp` / `mainwindow.ui`)

* **定位**：表现层控制器与视图，充当纯 C++ 内核与最终用户之间的胶水。
* **主要职责**：
* **事件监听**：监听界面输入事件与操作按钮（封装、单步、自动播放、暂停、重置）。
* **状态机与动画驱动**：维护 `current_step_index_` 游标与 `QTimer` 定时器。点击“单步”或定时器触发时，仅更新界面游标，直接从预存的 `crc_trace` 中提取切片刷新视图，杜绝界面卡顿。
* **报文可视化高亮**：利用 `FieldSpan` 信息，将连续 Hex 字节流分段赋予不同背景颜色（如前导码灰色、MAC 蓝色、长度绿色、Padding 黄色、FCS 橙色），点击字段实现双向联动高亮。



#### 7. Qt 主程序入口 (`src/main.cpp`)

* **定位**：GUI 程序生命周期起点。
* **主要职责**：
* 实例化 `QApplication`。
* 创建并展示 `MainWindow` 主窗口实例。
* 启动 Qt 的底层事件监听循环（`app.exec()`）。



#### 8. 构建配置文件 (`CMakeLists.txt`)

* **定位**：工程构建管理。
* **主要职责**：
* 配置 C++17 标准与 Qt6 组件依赖（`Core`, `Gui`, `Widgets`）。
* 将 `src/core/` 编译为名为 `EthernetCore` 的静态链接库。
* 声明可执行目标 `cli_test` 链接 `EthernetCore`。
* 声明可执行目标 `EthernetApp` 链接 `EthernetCore` 与 Qt6 模块。

### 三、模块协同与数据流转

```text
[ 用户在 UI 输入 MAC / Payload ]
                │
                ▼ (传入原始 std::string)
     ┌──────────────────────┐
     │    frame_builder     │
     └──────────┬───────────┘
                │
   ┌────────────┴────────────┐
   ▼                         ▼
utils (校验与清洗)       utils (Padding 与序列拼接)
   │                         │
   └────────────┬────────────┘
                ▼ (待校验字节流)
     ┌──────────────────────┐
     │      crc_engine      │ ──> [ 位流展开，逐步模拟模 2 除法 ]
     └──────────┬───────────┘
                ▼
     返回 (FCS 数值 + std::vector<CrcStepSnapshot>)
                │
                ▼
     组装出 EthernetFrame 实体
                │
                ▼
     交付 EncapsulationResult 给 MainWindow
                │
        ┌───────┴───────────────────────┐
        ▼                               ▼
[ 静态渲染区 ]                    [ 动态控制区 ]
- 高亮 HexDump (FieldSpan)        - 绑定 QTimer 与控制按钮
- 字段信息表格                     - 按 step_index 索引 Snapshot 回放

```
